# RahmonaPay - Personal Expense Tracker 💰

A modern, feature-rich expense tracking application built with Flask.

## Features

- 📊 Multiple Budget Types (Daily, Weekly, Monthly, Annual)
- 💵 Expense Management
- 📈 Visual Dashboard with Charts
- 📱 Smart Email/SMS Alerts
- 🌓 Dark/Light Theme
- 📧 Newsletter System

## Quick Start

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the app:
```bash
python app.py
```

3. Open browser:
```
http://localhost:5000
```

## Technologies

- Backend: Flask (Python)
- Database: SQLite
- Frontend: HTML5, CSS3, JavaScript
- Charts: Chart.js

```
## 🗂️ Important Notes:

### **About `.gitignore`:**
- The dot (`.`) at the start is important!
- **Windows users:** Windows might not let you create files starting with a dot
- **Solution for Windows:**
  1. Open Notepad
  2. Paste the content
  3. Save As → Type: "All Files (*.*)"
  4. Filename: `.gitignore` (with quotes)
  5. Save

### **File Location:**
All three files should be in your **main project folder**, like this:
```
